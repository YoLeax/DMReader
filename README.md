# DM Reader · 让弹幕自带声场

> [!IMPORTANT]
> **当前支持范围**
>
> - **弹幕来源**：目前仅支持通过面向**哔哩哔哩直播**的 **[LAPLACE](https://laplace.chat/)** 工具接入弹幕信息。暂不支持其他哔哩哔哩弹幕工具，也不支持 **Twitch** 等其他直播平台。
> - **语音生成**：目前仅接入**火山引擎的豆包语音**，暂不支持其他语音生成平台。

本机运行的哔哩哔哩弹幕 TTS 控制台。连接已登录的 LAPLACE Chat，用火山引擎豆包语音合成 2.0 播报。按真实 UID 保存观众的音色、风格、语速，重启和改名不丢失。

## 启动

环境：**Node.js 24 或更新版本**。本项目当前使用 Node 24 的内置 SQLite。

Windows 双击 `start.cmd`。它会安装缺失依赖、构建页面、启动服务并打开浏览器。保留启动窗口，按 Ctrl+C 停止服务。若服务已经运行，直接打开后台。

**关闭服务：双击 `stop.cmd`**。适用于没有可见启动窗口、或服务作为隐藏后台进程运行的情况；脚本会检查本机端口、DM Reader 健康检查和 Node 启动命令，只结束核对通过的目标进程，不批量结束其他 Node 程序。服务未运行时会提示无需关闭，执行完保留窗口显示结果。默认端口为 `23000`，也读取 `PORT` 环境变量；自定义端口可运行 `stop.cmd --port 23001`。

此脚本直接结束服务进程，正在处理的播报会中断；设置、密钥、观众偏好和已保存记录仍保留在 `data` 目录。关闭浏览器页面或点击「停止播放」只会停播放器，不会退出 Node 服务。正常用 `start.cmd` 启动后，优先在其可见窗口按 Ctrl+C；`npm run dev` 开发模式可能自动重启子进程，应在开发终端按 Ctrl+C 结束整个开发任务。

也可使用终端：

```powershell
npm ci
npm run build
npm start
```

后台：<http://127.0.0.1:23000>。服务仅监听 `127.0.0.1`。播放器默认自动开启；若浏览器拦截有声自动播放，页面会提示，点击页面任意位置或按键即可启用。开发时 `npm run dev`，页面在 <http://127.0.0.1:5173>。

所有管理页面均有固定 hash 地址：`#overview`、`#analytics`、`#events`、`#voices`、`#viewers`、`#designs`、`#logs`、`#settings`。刷新、直接打开链接及浏览器前进 / 后退均保留对应页面；空地址或无效 hash 自动归到 `#overview`。页面切换不会重新挂载全局播放器。

## 首次接入

1. 后台「接入与设置 → 火山引擎凭据」保存语音服务 **API Key**。也支持 App ID + Access Token。不是火山账号的通用 AK/SK。
2. 在 LAPLACE 设置 → Event Bridge 集成，填写主机 `127.0.0.1`、端口 `23000`，密码填后台显示的「本地 API 密钥」。开启自动连接，点击连接。
3. DM Reader 选择「精准互动模式」，房间号与 LAPLACE 相同。关闭 LAPLACE 的「自动语音播报」，避免两个播放器同时出声。
4. 本后台默认自动开启播放器，刷新后也会自动尝试启动。若提示浏览器尚未允许声音，点击页面任意位置或按键即可。保持 **LAPLACE 和本后台两个页面**开启；只能有一个后台页面持有播放权限，其他页面自动等待。
5. 到直播间发 `#音色 小何`，然后发送普通弹幕。后台可查看 UID、配置和合成记录。

手动停止后，本页面不会因点击其他控件再次自动启动；点击「恢复播放」可继续，刷新或重新打开页面则恢复默认自动启动。全局暂停、兼容 API 模式和未配置凭据时不会启动本地播放器。浏览器未允许播放时不领取播放任务、不调用合成。

停止播放器会清空待播队列；无播放器时跳过普通弹幕，但继续保存指令。等待超过 90 秒的弹幕会过期。关闭网页后播放器租约最多 20 秒释放。

## 弹幕指令

前缀支持 `#`、`＃`、`!`、`！`。命令和参数之间留一个空格。默认修改冷却 10 秒。

| 指令 | 效果 |
| --- | --- |
| `#音色 小何` | 支持短名、带 `2.0` 的名称、完整 ID 或被截断的 ID 前缀；多个匹配取目录中第一个 |
| `#风格 开心俏皮地说` | 持久保存标准音色的表达风格，最多 200 字 |
| `#风格 清除` | 清除个人风格，跟随直播间默认 |
| `#语速 1.2` | 0.5～2 倍，持久保存 |
| `#定制 温柔、略带沙哑的成年女声` | 提交专属音色申请，等待主播处理 |
| `#查询` / `#我的音色` | 语音回报当前音色、语速和风格，并记入活动记录 |
| `#音色列表` / `#帮助` | 在后台显示可选音色或指令说明 |
| `#重置` | 恢复直播间默认音色、风格、语速 |

`#音色` 匹配顺序：完整 ID → 精确名称 / 旧名称 → 去掉末尾 2.0 的名称 → ID 前缀。匹配忽略大小写、参数首尾空白和全半角差异；例如 `小何2.0`、`小何 2.0`、`小何（2.0）`、`小何 v2.0` 均可。ID 前缀必须从 ID 开头截取，不做中间片段搜索。空参数不会选中默认音色。多匹配取当前目录中第一个可选官方音色，保存的是完整 ID，后续目录变动不会重新匹配；确认语音会读出实际选中的名称。此宽松规则仅用于互动指令，管理配置与已保存 ID 保持精确解析。

命令原文不直接朗读；设置成功后用该观众的声音播报确认，例如“某某开始使用小何音色”“某某将语速改为 1.2 倍”。#重置、#定制 也有简短确认。反馈会使用语音额度，可在「事件播报」中独立关闭；关闭普通弹幕不影响指令生效。#查询 每人至少间隔 10 秒，长风格反馈按单条字数上限截短。#音色列表 / #帮助 只显示后台结果，不自动向直播间发送消息。观众档案支持静音、锁定、手动设置、JSON 导出与合并导入。

## 事件播报

后台左侧「事件播报」配置八种事件：普通弹幕、特效弹幕、礼物、SC、大航海、观众互动、进场特效、点赞。**普通弹幕和指令反馈默认开启，新增七类默认关闭**。观众互动还需同时开启对应 action：1 进场、2 关注、3 分享、4 特别关注、5 互相关注。设置保存后立即生效，无需重启。

所有本房间有效事件都会接收、解析并记录；关闭类型不排队、不调用豆包。活动记录可按事件类型与处理结果筛选，“最近事件结构”可切换查看每种类型的最新样本。日志仍只保留最近 3,000 条。

普通与特效弹幕读正文，SC 读发送者和正文；其余生成简短欢迎或感谢。事件有可靠 UID 时使用已保存的个人声音；缺少 UID 的普通弹幕仍跳过，其他有效事件使用默认声音，不用昵称关联身份。所有播报统一遵守静音、队列、缓存和额度保护。

礼物默认 10 秒、点赞 30 秒、欢迎 60 秒冷却。进场和进场特效共享欢迎冷却；礼物只读单条通知的数量，不将连击通知相加；点赞不推算次数。详见 [字段约定、防刷屏与验证记录](docs/event-support.md)。

## 数据看板

后台左侧「数据看板」，也可直接打开 <http://127.0.0.1:23000/#analytics>。支持今天、昨天、近 7 天、近 30 天，每 15 秒刷新；日期按北京时间（Asia/Hong_Kong）计算。单日显示每小时趋势，多日显示每天趋势，图表可切换指标、悬停或键盘聚焦查看数值。

- **直播互动**：弹幕量、正文字符数、发言观众、全部互动观众、八类事件分布、接收时处理结果、指令次数与失败数、活跃发言观众 TOP 8。
- **语音消耗**：时段 TTS 字数、标准和专属音色的本地累计预算、云端合成成功率、平均成功合成耗时、缓存复用率与估算节省字数、来源分布、热门音色 TOP 6。

弹幕包括普通 / 特效弹幕及其中的指令；按有效、去重后的事件计数，与是否开启播报无关。发言人数按可靠 UID 去重，同一 UID 改名不重复计人；不等于直播间在线人数。重复事件、字段异常单独计数；其他房间与不支持的事件不计入。本地模拟不计入真实弹幕、观众或指令数据，但模拟、试听、自定义 API 实际产生的语音均计入 TTS 消耗。

统计保存在 SQLite 的独立小时汇总表中，保留最近 **90 个自然日**，重启不丢失，不受活动日志 3,000 条上限影响。趋势从升级后开始采集，旧日志不回填；页面会标明记录起点。服务未运行或 Bridge 未连接期间的数据无法补录。

TTS 统计按请求发起时间和房间归档；成功后按服务返回字数校正，失败或不明结果继续保留预估消耗，缓存不新增字数。预算是整个本地服务的累计保护（标准预算包含「历史已用」），不是火山账户实时余额，也不受看板的日期筛选影响。合成成功不等于浏览器实际完成播放，队列后续跳过原因仍可在活动记录查看。

## 云端资源包余额

「直播控制台」「数据看板」「接入与设置」均显示**火山云端资源包余额**，标准 TTS 2.0 与声音复刻 2.0 分开显示。使用官方 `ResourcePacksStatus` 查询接口（版本 `2025-05-20`），复用音色同步已保存的 OpenAPI AK / SK，需要该动作的查询权限。此查询不调用语音合成、不消耗 TTS 字数；语音合成 API Key 不能用于查询。

默认查询火山项目 `default`，可在「查询设置」改为合成 API Key 所属的项目名称。服务运行期间默认每 5 分钟刷新，也可点击「查询云端额度」手动刷新（最短间隔 10 秒）。页面标明最近成功查询时间；页面轮询仅读取本地缓存，不会每次都请求火山。失败保留上次结果并提示过期，自动重试至少间隔 1 分钟；从未查询成功显示「—」，不会以本地预算或 0 冒充余额。更换 AK / SK 或项目后不沿用旧账户 / 项目的结果。最后一次成功结果和查询设置在重启后保留。

请求的计费资源 ID 为 `volc.seedtts.default` 和 `volc.seedicl.default`，与合成请求中的 `seed-tts-2.0` / `seed-icl-2.0` 不同。完整读取分页，只累计有效且未到期的预付费字数包，包括赠送资源包；按每个包的 `Harvest.PurchasedAmount` 与 `Harvest.CurrentUsage` 计算剩余字数。并发配额、音色槽位、其他资源和后付费额度不计入。资源包明细可以展开查看；接口字段、单位或分页异常时整次更新失败，避免用不完整数据覆盖旧结果。

这是云端查询时刻的资源包余额，火山侧用量可能有更新延迟；不受看板日期筛选影响，也不表示后付费是否能继续使用。原来的数字已明确改称「本地累计播报保护」，继续独立控制是否允许合成。查询不会自动调整本地上限、历史已用或观众配置。

## 音色与文字设计

内置 **445 个官方豆包 2.0 音色**（2026-10-01 对照官方主表 294 个与外语表 151 个，无重复 ID），包含 Lily。支持名称 / ID / 语种 / 场景搜索、语种筛选、试听和默认音色设置。名称与 ID 逐项取自官方资料，不根据名称拼接 ID。目录收录不等于当前账户逐项获得调用权限；未声明风格能力的音色以实际效果为准。

「音色实验室 → 官方音色同步」使用火山公开 **ListSpeakers** 接口，版本 `2025-05-20`，分页传入 `ResourceIDs: ["seed-tts-2.0"]`。后台可立即同步，并默认开启每日自动同步（需本服务运行且凭据已配置）。此操作只查询目录，不调用合成、不扣本地 TTS 字数预算。无需定期人工检查文档。

列表接口需要 **OpenAPI Access Key ID / Secret Access Key（AK / SK）**，与合成的 API Key 或 App ID + Access Token 不同。在此区域点击「配置同步凭据」，填入具有 `ListSpeakers` 查询权限的 AK / SK 后「保存并同步」。凭据独立加密保存在本机，不回显；也支持 `VOLCENGINE_ACCESS_KEY_ID` / `VOLCENGINE_SECRET_ACCESS_KEY` 环境变量。尚未配置时仍可使用完整的内置目录。AK / SK 可从 [火山 API 访问密钥](https://console.volcengine.com/iam/keymanage/) 页面新建；IAM 子账号需具备查询权限。

自动同步在启动后及每分钟检查到期时间，成功后间隔 24 小时；失败至少间隔 1 小时再自动尝试。一次同步会完成全部分页并检查字段、总数与重复 ID，然后保存；超时、网络失败、权限错误或异常分页都保留已有目录。按 ID 合并，保留旧名称和之前的音色，避免上游改名或临时缺项影响已保存的观众偏好；音色指令遇到同名或 ID 前缀多匹配时，按当前目录顺序选择第一个；已保存的完整 ID 仍精确查找。同步后立即用于指令解析，音色页自动刷新目录。

**说话风格**通过 `req_params.additions` 中的 `context_texts` 设置。它调节已有声音的情绪、口音与表达，不能保证创造新的音色。

**文字设计新音色确实有官方 API**：`POST /api/v3/tts/voice_design`，传入 `speaker_id` 与 `prompt.text_prompt`。本应用使用申请审核流程：

1. 观众发 `#定制 描述`，此时只保存本地申请，不调用火山。
2. 主播到火山「音色设计 / 声音复刻」核对一个可用的**空槽位**，复制 `S_` 开头的 ID。
3. 在后台申请页面选「审核并生成」，确认空槽位，再执行。会消耗这个槽位的一次更新机会。
4. 成功后自动将槽位绑定到该观众。后续合成使用 `seed-icl-2.0`，与标准音色的 `seed-tts-2.0` 不同。
5. 核对声音复刻的额度后，在设置中填写「专属音色合成上限」。默认 **0 字**，避免把标准 TTS 免费字数误当成复刻额度。

本地已经绑定过的槽位不可再次生成。云端既有槽位是否为空仍需主播核对。网络错误、未就绪、服务重启导致结果不确定时标记「需要核对」，**不自动重试**；确认云端成功后可手动绑定，确认失败可关闭申请。不会自动购买槽位或资源包。

专属音色保持设计时的风格，不附加标准音色的 `context_texts`。本次交付已用真实凭据验证标准音色合成；没有实际生成专属音色，相关路径用模拟上游进行了测试。

## LAPLACE 自定义 API

```http
POST http://127.0.0.1:23000/v1/tts
Content-Type: application/json
```

```json
{
  "token": "从本地后台复制的 API 密钥",
  "text": "你好，直播间！",
  "voice": "小何",
  "instructions": "轻松自然地说话"
}
```

成功返回 `audio/mpeg` 音频本体。命令和精准模式的此接口返回短静音 WAV。错误返回非 2xx JSON，LAPLACE 可据此识别请求失败。支持 `OPTIONS` 和显式 CORS 来源；默认允许 `https://laplace.chat`、`https://chat.laplace.live`、`https://laplace.live`。

**为何需要 Event Bridge**：LAPLACE 自定义 API 只传 `token/text/voice/instructions`，不带观众 UID，而且可能合并同文弹幕。仅凭这四个字段无法可靠识别是谁。因此精准互动模式从 Event Bridge 直接接收事件，在本地后台播放；此模式 `/v1/tts` 返回静音，防止重复扣量和重复播放。

「兼容 API 模式」可完全交给 LAPLACE 播放，但 LAPLACE 请求只能使用统一的音色配置。其他自建客户端可额外提交 `uid` 和 `username` 来应用个人偏好；这不是 LAPLACE 默认会传的字段。

内置桥实现了官方 producer 协议的握手、密码、心跳和广播确认，不需要另外启动 Go Event Bridge。支持上述八种事件，并按开关控制是否播报。其他 Event Bridge 消费者请继续使用独立官方桥，本服务不是通用事件转发器。

## 用量、数据和运行边界

- 标准音色本地累计上限默认 19,000 字。可填写「接入前已使用」或调整上限。**这是本机保护预算，不是火山实时余额**，也无法追踪其他应用对同一账户的消耗。
- 合成前先预留估算字数，成功后以云端返回的 `usage.text_words` 结算；失败和超时保留预估用量。音频一小时缓存，最多 100 条 / 20 MB，匹配内容、音色、风格、语速后直接复用，不重复调用云端。重启清空音频缓存。
- 默认一条最多 120 字、队列 15 条、每分钟最多 60 次云端合成、并发合成串行化；可配置屏蔽词、指令开关。所有云端请求均使用固定的火山官方 HTTPS 地址。
- SQLite 数据：`data/dmreader.sqlite`，包括偏好、使用计数、指令冷却、事件去重和最近 3,000 条日志。去重记录保留 7 天。日志中含弹幕和 UID，仅留在本机。
- API 凭据以 AES-256-GCM 加密，密钥在 `data/local.key`。此加密不防御已能读取整个数据目录的本机用户；请保护整个目录，不要提交到 Git。云端密钥不回传网页、日志或偏好备份。
- 「导出偏好」不含任何密钥，导入按 UID 合并并覆盖相同 UID 的偏好，不删除其他观众。需要完整迁移时，先停止服务，再复制整个 `data` 目录，包括 `local.key`。
- 管理接口要求本机 Host、来源检查和进程级随机后台令牌；TTS 与桥使用独立的持久本地密钥。不要把服务直接代理到公网。
- 可用环境变量：`PORT`、`DMREADER_DATA_DIR`、`DOUBAO_API_KEY`，或 `DOUBAO_APP_ID` + `DOUBAO_ACCESS_KEY`。环境变量中的云端凭据优先于页面保存值。修改端口时同时调整 LAPLACE 配置。
